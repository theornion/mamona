V3.4 — subagent edit inheritance fix

ROOT CAUSE:
Task-spawned child może odziedziczyć `edit: deny` parenta.
To usuwa edit/write/apply_patch z active toolset childa.

PO INSTALACJI:
1. Developer: Reload Window.
2. Uruchom NOWĄ sesję mamona-orchestrator.
3. Sprawdź `kilo.cmd agent list`:
   - mamona-orchestrator: edit = ask
   - mamona-tester: edit = allow
   - mamona-coder: edit = allow
4. Uruchom tylko P3-PREFLIGHT-WRITE.
5. Tester ma utworzyć `.kilo/results/P3-PREFLIGHT-WRITE.json` natywnym file tool.
6. Jeśli preflight przejdzie, dopiero uruchom P3-A.

WAŻNE:
Orchestrator nie może sam edytować plików mimo edit=ask.
Jeżeli pojawi się approval na edit wykonany przez Orchestratora — DENY.
